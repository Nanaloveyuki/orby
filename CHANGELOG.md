# Changelog

## 0.1.0

- Win32 and GTK3/GDK native windows, lifecycle, geometry, display snapshots,
  basic input, fullscreen, and MoonView host integration.
- Checked initialization, geometry, monitor, and WebView-host lifecycle errors.
- Native CI gates for Orby and MoonView smokes on Windows and Linux.

## Compatibility

0.1.0 is the initial public API. It supports only the platform-specific
`Nanaloveyuki/orby/windows` and `Nanaloveyuki/orby/linux` packages.
